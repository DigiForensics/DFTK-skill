# DFTK-skill repository guidance

This repository is an Agent Skill bundle. Preserve the root `SKILL.md`, the
`references/` directory, and every directory under `skills/` when installing it.

DFTK is the primary bootstrap repository. When DFTK installs this bundle, follow
[INSTALL_AGENT.md](INSTALL_AGENT.md). Do not silently install DFTK into multiple
Agent hosts; select the current host explicitly or present a dry-run plan when it
cannot be detected.
