# DFTK Skill 3.6.0

This release aligns the guidance bundle with the integrated DFTK 3.6.0 runtime:
127 capabilities in 28 domains, seven MCP meta-tools, and 31 specialist workflows.

- Regenerate capability and specialist catalogs from the maintained manifests.
- Preserve the primary DFTK bootstrap, one-host installation and separate evidence /
  case workspace contract from 3.4.
- Add explained input/output discovery and browser bookmark/cookie/search procedures.
- Add native Mach-O inventory and byte-comparison procedures to reverse workflows.
- Add concrete native evidence anchors and inference boundaries to every specialist.
- Explain full Observation, persisted artifact, evidence-item and finding integrity,
  excluded WAL state, parser bounds and optional dependency limitations.

Install the whole bundle with `dftk skill --install` using DFTK 3.6.0. The matching
GitHub tag is `v3.6.0`. Capability availability comes from the installed runtime;
method-only specialist guidance does not imply that DFTK supplies a third-party
decompiler, memory engine, cryptographic verifier or live analysis sandbox.
