# ot-ics

Authorized OT/ICS security assessment: Purdue-model zoning, PLC/SCADA exposure,
industrial-protocol discovery, and safe passive-first evaluation.

- Passive-first by default; physical harm is possible, so written authorization and
  read-only stance are mandatory.
- Pairs with `protocol-reverse` (traffic) and `firmware-forensics` (controller firmware).
