# macos-reverse

Authorized macOS / Mach-O reverse engineering: codesign / notarization inspection,
Objective-C / Swift recovery, endpoint-security (TCC / Hardened Runtime) review,
and Apple-platform malware analysis.

- Read-only-first, evidence-preserving.
- iOS/IPA routes to `mobile-reverse`; deep decompilation to `ida-reverse` /
  `ghidra-reverse`.
