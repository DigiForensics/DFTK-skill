# browser-extension-reverse

Authorized reverse engineering of browser extensions (Chrome/Edge MV2/MV3, Firefox):
manifest analysis, background-worker / service-worker recovery, content-script
injection, and extension-based credential / traffic logic recovery.

- Read-only-first, evidence-preserving.
- Covers malicious-extension IOC extraction and supply-chain poisoning
  investigation. For plain web JS, use `js-reverse`.
