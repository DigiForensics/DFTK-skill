# digital-forensics

Authorized digital forensics & incident-response triage for DFTK-skill. Covers memory (Volatility 3), disk/E01 super-timelines (Plaso), host artifacts (Prefetch/Shimcache/Event Logs/browser), and IR preservation.

This skill complements — not replaces — DFTK: use DFTK for the file-level artifacts it already parses; use this skill for system-level acquisition, timeline fusion, and chain-of-custody. Enable the DFTK 3.4.0 audit ledger when running any command so the process itself is recorded with evidence hashes.

See `SKILL.md` for the full workflow.
