# ghidra-reverse

Open-source reverse engineering with Ghidra (headless or GUI): project import,
auto-analysis, decompilation, cross-references, and optional Ghidra MCP workflows.

- Read-only-first, evidence-preserving; the decompiler entry when no IDA license
  exists.
- Covers batch headless analysis and the Ghidra MCP bridge.

## Files

- `SKILL.md` — the methodology.
- `references/cheatsheet.md` — command reference.
- `CHANGELOG.md`
- `LICENSE` — Apache-2.0.
