# go-rust-reverse

Reverse engineering of stripped Go and Rust binaries: runtime recognition,
pclntab / module-data recovery (GoReSym), panic-string analysis, and idiomatic
decompilation recovery.

- Read-only-first, evidence-preserving.
- Complements `ida-reverse` / `ghidra-reverse` / `radare2` for the generic
  disassembly part.
