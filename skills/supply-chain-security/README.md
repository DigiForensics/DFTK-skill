# supply-chain-security

Software supply-chain security assessment: SBOM generation/audit, SCA, CI/CD pipeline
review, container-image analysis, build integrity, dependency provenance, and
vulnerability reachability.

- Defensive, evidence-preserving; SCA alert ≠ exploitable — verify reachability first.
- Regulation-aware (SBOM mandates, EU CRA).

- `SKILL.md` — the methodology.
