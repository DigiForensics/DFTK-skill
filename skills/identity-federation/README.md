# identity-federation

Authorized assessment of federated identity: SAML / OIDC / OAuth2 SSO flows,
misconfiguration review, and token-confusion analysis.

- Read-only-first, evidence-preserving; map the flow, find misconfigs, recommend fixes.
- Pairs with API-security review (JWT) and `server-forensics` (enterprise IdP).
